# Proteus project files

Place your Proteus project and schematic files in this directory, for example:

- `Experiment_1_Smart_Home_Safety.pdsprj`
- The associated schematic or project files generated by your Proteus version.

Also note the external model-firmware requirements for the MQ-2, PIR, and ultrasonic components. Those model HEX files are not interchangeable with `code/SmartHomeSafety.ino`'s compiled Arduino firmware. If sharing the project, ensure any third-party library licenses permit redistribution and document model dependencies here.

The Proteus project itself has not been included in this starter archive because it must be copied from the user's actual project directory.
