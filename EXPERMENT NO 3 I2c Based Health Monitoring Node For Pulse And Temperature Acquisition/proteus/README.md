# Proteus project files

Place the native Proteus project and all associated schematic/library/model files in this folder.

Expected project name:

`Experiment_3_I2C_Health_Monitoring.pdsprj`

The native Proteus project was not included in this starter package because only a schematic screenshot was supplied in the conversation. The file `../output/current_schematic_reference.png` is a visual reference, not an editable Proteus project.

Before sharing the project, check that:

- The Arduino UNO Program File points to the compiled `HealthMonitoringNode.ino.standard.hex`.
- The Heart Beat Sensor Program File points to the matching sensor-library firmware HEX, if required by that model.
- Any required DLL/model files and library dependencies are available to the recipient and may legally be redistributed.
- Absolute paths to files on your own PC are not the only way the project can locate its models.

See `wiring_reference.md` for the intended pin assignments.
