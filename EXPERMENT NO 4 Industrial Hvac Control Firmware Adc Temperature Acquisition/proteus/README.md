# Proteus project files

Place the native Proteus project (`.pdsprj`) and all associated schematic / library support files in this folder before publishing.

The repository currently contains only `wiring_reference.md`; the submitted image is stored in `output/schematic_reference.png` as a visual reference. A screenshot is not a substitute for an editable Proteus project.

When sharing the project, verify that any custom component models are available to the recipient and that model / firmware paths do not point to temporary folders or user-specific absolute paths.
