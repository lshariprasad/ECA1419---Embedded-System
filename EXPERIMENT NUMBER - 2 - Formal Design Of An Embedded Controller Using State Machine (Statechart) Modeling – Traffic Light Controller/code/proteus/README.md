# Proteus files

Place the native Proteus project and any associated schematic/dependency files in this folder. For example, keep the `.pdsprj` file together with all project files created by Proteus when saving the project.

**The native project is not included in this starter ZIP** because only a screenshot of the schematic was available during packaging. Do not rename a text placeholder to `.pdsprj`; it would not be a real Proteus project.

See `traffic_light_wiring_reference.md` for the verified intended pin map and setup notes. A schematic screenshot is retained in `../output/traffic_light_circuit_reference.png`.
