# Arduino source code

- `TrafficLightController.ino` is the complete Arduino UNO firmware for Experiment 2.
- Uses only built-in Arduino functions; no third-party libraries are required.
- Pinout: RED D8, YELLOW D9, GREEN D10.
- Durations: RED 5000 ms, GREEN 5000 ms, YELLOW 2000 ms.

Compile for **Arduino UNO / ATmega328P**. Export the compiled HEX from Arduino IDE before loading it into Proteus.
