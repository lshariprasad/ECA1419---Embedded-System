# Output and evidence

This folder contains the FSM diagram, reference circuit screenshot, expected sequence, and a test-results template.

- `fsm_statechart.png` / `.svg`: FSM state-transition diagram.
- `traffic_light_circuit_reference.png`: screenshot of the schematic arrangement shared during project setup. It is a **circuit reference**, not a successful simulation-result screenshot.
- `experiment_report.md`: report structure with expected behavior and a section to fill after testing.
- `test_results_template.csv`: record real observed results here after simulation.

Before submitting your lab, capture fresh Proteus screenshots showing RED, GREEN and YELLOW states and replace/add those images here. Do not mark tests PASS until you have observed them.
